# Changelog

## v0.1.0 - 2026-03-18

### Added

- Python desktop app for Windows 11 audio recording
- M4A (AAC) recording support via FFmpeg
- Optional formats: AAC, MP3, WAV, FLAC, OGG Vorbis
- Configurable quality options for sample rate, channels, and bitrate
- Presets for meeting, voice, music, and custom
- Automatic file rotation by size or duration
- Default meeting preset with 180 MB split
- Tray icon support with start, stop, restore, and quit actions
- Persistent settings stored in `config.json`
- Packaging scripts for `PyInstaller`
- MIT license
